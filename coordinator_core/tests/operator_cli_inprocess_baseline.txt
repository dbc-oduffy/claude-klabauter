# DR-276 baseline — operator-CLI entrypoints that import coordinator_core.ops
# in-process WITHOUT routing through coordinator_core.cli_entry.run_op_main.
#
# These began as the trampolines the 2026-08-06 triage classified as bucket (c)
# (`state/audits/operator-cli-triage/`): a shared, near-byte-identical template,
# not independent decisions — a KNOWN backlog. Converting one means deleting its
# line here.
#
# 2026-08-06, end of the conversion sweep: 110 of the original 155 were
# converted (see git log for DR-276). **The 45 that remain are no longer an
# undifferentiated backlog** — every one was individually classified during that
# sweep, with per-file evidence in `state/subagent-share/`. They fall in four
# kinds, and the practical consequence is that this list is now mostly
# PERMANENT, not pending:
#
#   1. Structurally read-only — the op has no write site to declare, so routing
#      buys an import hop and a permanently-empty declaration list.
#   2. Already on the wire path — reaches the engine via `cc_invoke.route` /
#      `route_mutation` / `dispatch_message`, the very chokepoint this seam
#      backfills for in-process importers. Converting would fork a second
#      recording path, which is the harm, not the fix.
#   3. Mutates git refs or the index, never file content (branch renames,
#      `git config`, worktree reaping) — nothing a scope-touch claim models.
#   4. Genuinely deferred, and only these: `publish.py` (owns a 4716-line
#      `main()`; its writes land in sibling repos across dozens-to-hundreds of
#      files per target, so whether cross-repo publish output belongs in the
#      calling session's claim is a design question, not a mechanical one) and
#      `archive-stamp-cli` (every subcommand's write lands 2+ layers down in
#      ~15 handler-owned op modules; a partial pass would silently miss some).
#
# Do not re-attempt kinds 1-3 as if they were backlog. Kind 4 is the only real
# residual.
#
# The gate in test_operator_cli_engine_contact.py fails only on entries NOT in
# this file, so regrowth is caught while conversion stays incremental.
#
# Adding a line to this file is a carve-out. Say why, inline, or it will be
# deleted by the next reader as unexplained.
#
# SANCTIONED CARVE-OUTS — the entries below are NOT backlog. Each imports
# coordinator_core.ops in-process for a reason the seam does not address, and
# each is classified bucket (a), correct as-is. They are permanent; do not
# "convert" them.
#
# `update-docs-probes.py` (triaged 2026-08-06, was UNTRIAGED): imports gate
# FUNCTIONS from coordinator_core/ops/updatedocs_gates.py, which is a library
# of `_gate_*` predicates with no `main(argv)` for run_op_main to route to. The
# CLI's actual job is per-subcommand exit-code translation — the same
# GateVerdict maps to 0 in one subcommand and 1 in another — which is CLI-
# boundary logic the op deliberately leaves to its callers. It writes nothing
# itself; its one mutating path shells out to prune-resolved-queue-entries.py,
# which declares the write at the real write site.
#
# `cartography.py`'s 2026-08-06 triage note — "its only coordinator_core.ops
# import is `_registry_map.OP_MODULE_MAP`, a static data map read at call time,
# not an op invocation" — turned out to describe a whole CLASS, not one file.
# The gate's `_imports_an_op_in_process` credited ANY import from the package,
# so a private helper, a constant enum, or a path-derivation function read as
# an op reach. That predicate now requires an op ENTRYPOINT (see the function's
# own docstring for the four live specimens and the fail-closed narrowness),
# and these four left this file as a result — they were never bypasses:
#   cartography.py (`_registry_map.OP_MODULE_MAP`),
#   archive-stamp-cli (`handoff_stamp._SHIPPED_IN_KIND_ENUM`),
#   handoff-archive-transition.py (`fleet._common.handoff_archive_dest`),
#   query-records.py (`records_query._TYPE_TO_GLOB`).
# Carry-forward: `archive-stamp-cli` is still kind-4 residual debt on its own
# merits (its writes land 2+ layers down in ~15 handler-owned op modules), but
# that debt is no longer visible to THIS gate and is not tracked by a row here.
#

# through `coordinator_core.invoke.dispatch.dispatch_message` — the very
